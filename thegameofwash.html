The Game of Wash


Status: Customizations complete, including upsell feature and custom built testimonial section.

The above video shows an upsell feature I built for The Game of Wash, which sells a hand crafted yard game called Wash.

This upsell feature lets customers add extra dice to their order on the fly. This greatly simplified the process for the client as, previously, off platform arrangements had to be made when selling these dice. This feature was also designed to only be included with certain collections.

Other customizations included...

  • Adding a new collection with new products
  • Edited social media icons to have external hyperlinks
  • A testimonial slider for the homepage
  • A dedicated testimonials page

Testimonials were setup as a metobject so store owner can edit within his dashboard without touching any code.

In addition, a recent audit was performed on this store. Changes to be initiated will be detailed here soon.
